# Fonts

The app's own faces, served by the site so it needs no third-party font host.

| file                                       | face, cut                          | used for                         |
| ------------------------------------------ | ---------------------------------- | -------------------------------- |
| `archivo/Archivo-SemiExpandedExtraBold.ttf` | Archivo SemiExpanded ExtraBold     | headings, buttons, the wordmark  |
| `archivo/Archivo-ExtraCondensedBlack.ttf`   | Archivo ExtraCondensed Black       | shirt numbers                    |
| `ibm-plex-mono/IBMPlexMono_600SemiBold.ttf` | IBM Plex Mono SemiBold             | small capital labels             |

Body text uses the visitor's system font.
