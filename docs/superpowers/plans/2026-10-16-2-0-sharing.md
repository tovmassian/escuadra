# 2.0 Sharing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Results' share icon opens a sheet that shares the round as a 1,080×1,920 picture or as today's text, with the telemetry and privacy text that go with it (#114, part 2 of 2).

**Architecture:** Pure copy and parts live in `lib/shareResult.ts`. The capture and hand-off live in `lib/share.ts`, the only importer of `react-native-view-shot` and `expo-sharing`. `components/ShareCard.tsx` draws the picture at 360×640 pt and scales to any width, so one layout serves the preview and the capture. `components/ShareSheet.tsx` is a transparent `Modal` with the Image/Text switch, the preview and the button. Results owns the sheet's visibility and the `track()` call.

**Tech Stack:** Expo SDK 57, React Native 0.86, React 19.2, Reanimated 4.5.1, `react-native-view-shot`, `expo-sharing`, Vitest (node, no RN renderer).

**Spec:** `docs/superpowers/specs/2026-10-15-play-redesign-2-0-design.md`: §4 (sharing), §6 (the share-sheet motion row), §10.2–10.3 (privacy), §12 and §13. The design board's share sheet and card are summarised in the tasks below, with their values.

## Global Constraints

- **Image content:** score, number grid, team colours and link. No player photos or names (spec §1).
- **Third-party logos:** none are drawn. Sharing goes through the phone's own share menu.
- **New packages:** exactly `react-native-view-shot` and `expo-sharing`, through `npx expo install`. No other dependency change.
- **Capture:** at 1,080×1,920 px, with `format: 'png'`, `quality: 1`, `result: 'tmpfile'`, `width: 1080 / PixelRatio.get()` and `height: 1920 / PixelRatio.get()`.
- **Hand-off:** `Sharing.shareAsync(uri, { mimeType: 'image/png', UTI: 'public.png', dialogTitle: 'Share your round' })`.
- **Text:** unchanged. `formatShareText`'s output is byte-identical, and it is sent with `Share.share({ message })`.
- **Telemetry:** `result.shared` gains `format: 'image' | 'text'`.
  - Text is tracked on `Share.sharedAction`.
  - Image is tracked when `shareAsync` resolves.
- **Web:** the sheet renders, but "Share image" does nothing.
- **Motion:**
  - scrim 200 ms;
  - sheet slides up 240 ms, with no overshoot;
  - switch pill slides 160 ms;
  - preview crossfades 150 ms;
  - with Reduce Motion, opacity only, 150 ms.
- **Tokens only** (guardrail 5): add a missing token rather than inline a value; a palette role goes into both palettes.
  - Ruling: `ShareCard` draws in `palettes.dark` on purpose. The picture is the same in whichever theme it is shared. CLAUDE.md guardrail 5 gains one sentence saying so.
- **TypeScript:** strict with `noUncheckedIndexedAccess`; no `!`, no `any`.
- **Bold faces:** no `fontWeight` on Archivo, Inter-Bold or Inter-ExtraBold styles (#117).
- **Tests:** the files `lib/*.test.ts` stay beside their code (that area has not moved to `__tests__/`).
- **Verification:** `npm run check` passes before every commit (`nvm use` first; Node 24).

```ts
// Pure model for sharing a result (spec §4): the text message for chat apps,
// and the copy on the share picture. Plain text and drawn squares only — no
// flag emoji (they depend on an OS font; CLAUDE.md guardrail 2), nothing
// crest-like, and never a player's name or photo (spec §1).

import { isFlawless, resultTier, type ResultTier } from '@/lib/resultsView';

/** The marketing site links both stores; a store URL is wrong on the other platform. */
export const SHARE_URL = 'https://tovmassian.github.io/escuadra/';

/** The link as the share picture prints it: no scheme, no trailing slash. */
export const SHARE_URL_DISPLAY = SHARE_URL.replace(/^https:\/\//, '').replace(/\/$/, '');

/** How a result leaves the device; also `result.shared`'s `format`. */
export type ShareFormat = 'image' | 'text';

export interface ShareInput {
  teamName: string;
  level: number;
  /** One entry per question, in order. `null` (unanswered) is left out. */
  outcomes: (boolean | null)[];
}

/** The message's pieces, which the share sheet's preview draws as a chat bubble. */
export interface ShareTextParts {
  header: string;
  score: string;
  /** "a la escuadra" on a flawless round, otherwise null. */
  verdict: string | null;
  /** Answered questions only, in order. */
  squares: boolean[];
  url: string;
}

export function shareTextParts({ teamName, level, outcomes }: ShareInput): ShareTextParts {
  const squares = outcomes.filter((o): o is boolean => o !== null);
  const correct = squares.filter(Boolean).length;
  return {
    header: `Escuadra · ${teamName} · Level ${level}`,
    score: `${correct}/${squares.length}`,
    verdict: isFlawless(correct, squares.length) ? 'a la escuadra' : null,
    squares,
    url: SHARE_URL,
  };
}

export function formatShareText(input: ShareInput): string {
  const { header, score, verdict, squares, url } = shareTextParts(input);
  const grid = squares.map((o) => (o ? '🟩' : '🟥')).join('');
  return [header, `${score}  ${verdict ? `${verdict}  ` : ''}${grid}`, '', url].join('\n');
}

/** One question on the share picture: its shirt number and whether it was right. */
export interface ShareItem {
  no: number;
  correct: boolean;
}

export interface ShareCardInput {
  teamName: string;
  season: string;
  level: number;
  /** The round strip's items, in order. */
  items: readonly ShareItem[];
}

export interface ShareCardView {
  /** "Spain · 2026 · Level 2"; the card sets it in capitals. */
  eyebrow: string;
  correct: number;
  total: number;
  tier: ResultTier;
  title: string;
  question: string;
  link: string;
}

// "Spain's", but "Netherlands'".
function possessive(name: string): string {
  return name.endsWith('s') ? `${name}'` : `${name}'s`;
}

// Results' fail title ("These are the ones to learn") speaks to the player;
// the picture speaks to whoever receives it, so a fail reads "Still learning".
const TITLES: Record<ResultTier, (level: number) => string> = {
  fail: () => 'Still learning',
  passed: (level) => `Level ${level} cleared`,
  excellent: () => 'A la escuadra',
};

export function shareCardView({ teamName, season, level, items }: ShareCardInput): ShareCardView {
  const correct = items.filter((i) => i.correct).length;
  const tier = resultTier(correct, items.length);
  return {
    eyebrow: `${teamName} · ${season} · Level ${level}`,
    correct,
    total: items.length,
    tier,
    title: TITLES[tier](level),
    question: `Can you name ${possessive(teamName)} squad?`,
    link: SHARE_URL_DISPLAY,
  };
}
```

```ts
// The share hand-off (spec §4): captures the share card as a picture, or
// passes the text, to the phone's own share menu. The only module that imports
// `react-native-view-shot` and `expo-sharing`. Callers catch: a share menu
// that fails to open is not worth interrupting the results for.

import { shareCapture } from '@/theme/tokens';
import * as Sharing from 'expo-sharing';
import type { RefObject } from 'react';
import { PixelRatio, Platform, Share, type View } from 'react-native';
import { captureRef } from 'react-native-view-shot';

/**
 * Captures `card` at `shareCapture` pixels and opens the share menu with it.
 * True once the menu has closed: Expo cannot tell whether the picture was
 * sent, so that is what `result.shared` counts for an image (spec §10.3).
 * False on web, where the button does nothing (spec §4.2), or when the device
 * cannot share a file.
 */
export async function shareImage(card: RefObject<View | null>): Promise<boolean> {
  if (Platform.OS === 'web' || !(await Sharing.isAvailableAsync())) return false;
  const uri = await captureRef(card, {
    format: 'png',
    quality: 1,
    result: 'tmpfile',
    width: shareCapture.width / PixelRatio.get(),
    height: shareCapture.height / PixelRatio.get(),
  });
  await Sharing.shareAsync(uri, {
    mimeType: 'image/png',
    UTI: 'public.png',
    dialogTitle: 'Share your round',
  });
  return true;
}

/** Opens the share menu with `message`. True only when the OS reports it was sent. */
export async function shareText(message: string): Promise<boolean> {
  const outcome = await Share.share({ message });
  return outcome.action === Share.sharedAction;
}
```

4. **Submit:**

```ts
const submit = async () => {
  if (busy) return;
  setBusy(true);
  try {
    const sent =
      format === 'image' ? await shareImage(cardRef) : await shareText(formatShareText(text));
    if (sent) onShared(format);
  } catch {
    // A share menu that fails to open is not worth interrupting the results.
  } finally {
    setBusy(false);
  }
};
```

- **The sheet stays open after a share.** Ruling: the user can share the other format too, and closing is one tap. Expo cannot say whether an image was sent, so closing on resolve would also close it on a cancel.
- **Colour** comes from `useThemeColors()` and **insets** from `useSafeAreaInsets()`. The header comment names spec §4.1 and says why the capture card is a second, off-screen copy.
