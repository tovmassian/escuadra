## Global Constraints

- **Header:**
  - back, then a "Hide names" toggle, then a grid/list toggle;
  - the team banner, "SPAIN · 2026" (name and season), then "SQUAD" and a count: "26 players", or "9 of 26" when filtered.
- **Filters:** All / GK / DF / MF / FW pills with counts. Rows are sorted by shirt number.
- **Grid** is the default view: two columns of `PlayerCard`s, 218 pt tall (`sizes.playerCard.studyHeight`).
- **List:** 64 pt rows with a 46 pt avatar (`sizes.avatar`).
- **`studyView`:** the grid/list choice persists in `stores/progress.ts` as `studyView: 'grid' | 'list'`, default `'grid'`. It survives `reset()`, as the other preferences do.
- **Hide names:**
  - each name becomes a dashed "Tap to reveal" pill, and a tap reveals it with `feedback('reveal')`;
  - turning Hide names off or on clears the reveals;
  - it is not persisted.
- **Photo credits:** "Photo credits · N" at the end of the list. Each row names its photo by shirt number only, so Hide names is never spoiled.
- **Loading:**
  - lists are virtualised (`FlatList`, `numColumns={2}` in the grid);
  - photos load as cards mount, never a whole squad at once (spec §9), so set a small `initialNumToRender` and `windowSize`;
  - there is no prefetch on Study.
- **Motion:** cards fade in as they mount, 150 ms (`durations.transition`); a reveal crossfades the name in, 180 ms (`durations.reveal`). Reduce Motion keeps the fades, which are opacity only.
- **Telemetry:** `study.opened` is unchanged. Hide names and the view toggle are not tracked.
- **About:**
  - The stored-data list becomes **eight** things.
  - The "Player photos" privacy paragraph takes spec §10 item 1's text word for word.
  - The credits paragraph says where Study's credits are.
- **CLAUDE.md:**
  - guardrail 1 says where Results' and Study's credits sit;
  - guardrail 7 holds: About stays true.
- **Tokens only** (guardrail 5). Add a missing token instead of inlining a value, and add a palette role to both palettes. Colour comes from `useThemeColors()`.
- **No `fontWeight`** on Archivo, Inter-Bold, Inter-ExtraBold or IBMPlexMono-Bold styles (#117).
- **TypeScript:** strict with `noUncheckedIndexedAccess`. No `!`, no `any`.
- **Tests:** the `lib/*.test.ts` files stay beside their code.
- **Verification:** `npm run check` passes before every commit (`nvm use` first; Node 24). `npm run shots` starts its own web server on port 8082; never stop the user's server on 8081.

// Pure Study-screen model (spec §5.1): which players show and in what order,
// the filter pills' counts, the header's count, each player's affiliation
// line, what a screen reader hears, and the photo credits. Kept out of the
// screen so it is unit-testable.

import { photoFor, type PhotoCreditRow } from '@/lib/photos';
import { positionLabel } from '@/lib/roundView';
import type { Player, Position, RosterEntry, Squad } from '@/types/squad';

export type StudyFilter = 'ALL' | Position;
export const STUDY_FILTERS: readonly StudyFilter[] = ['ALL', 'GK', 'DF', 'MF', 'FW'];

/** Cards in two columns, or a compact list. Persisted in `stores/progress.ts`. */
export type StudyView = 'grid' | 'list';

/** Rows to show, always in shirt-number order. */
export function studyRows(roster: RosterEntry[], filter: StudyFilter): RosterEntry[] {
  return roster
    .filter((r) => filter === 'ALL' || r.player.position === filter)
    .sort((a, b) => (a.member.no ?? Infinity) - (b.member.no ?? Infinity));
}

/** Each pill's count, over the whole squad. */
export function filterCounts(roster: RosterEntry[]): Record<StudyFilter, number> {
  const counts: Record<StudyFilter, number> = { ALL: roster.length, GK: 0, DF: 0, MF: 0, FW: 0 };
  for (const r of roster) counts[r.player.position] += 1;
  return counts;
}

/** The header's count: "26 players" unfiltered, "9 of 26" filtered. */
export function studyCount(shown: number, total: number, filter: StudyFilter): string {
  if (filter !== 'ALL') return `${shown} of ${total}`;
  return `${total} ${total === 1 ? 'player' : 'players'}`;
}

/** The line under a name: a club squad's players show their nationality
 *  (with its flag), a nation squad's their club. */
export function studyAffiliation(player: Player, kind: Squad['kind']): string {
  return kind === 'club' ? player.nationality : (player.club ?? '—');
}

/** What a screen reader hears for a player. With Hide names on, the name is
 *  never spoken; the rest is no spoiler. */
export function studyLabel(
  no: number,
  player: Player,
  affiliation: string,
  hidden: boolean,
): string {
  const name = hidden ? 'name hidden' : player.name;
  return `${no}, ${name}, ${positionLabel(player.position)}, ${affiliation}`;
}

/** The credits for the photos in the list, in list order. Study's credit
 *  rows name each photo by shirt number only, so they never spoil Hide names. */
export function studyCreditRows(rows: RosterEntry[]): PhotoCreditRow[] {
  return rows.flatMap((r) => {
    const credit = photoFor(r.player);
    return credit
      ? [{ playerId: r.player.id, memberNo: r.member.no, playerName: r.player.name, credit }]
      : [];
  });
}
