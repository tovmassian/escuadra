# #114 part 1 — The rebuilt Results screen: Implementation Plan

**Issue:** [#114](https://github.com/tovmassian/escuadra/issues/114), part 1 of 2. Part 2 adds the share sheet, the share image, telemetry `format` and the privacy text. **Milestone:** [v2.0.0](https://github.com/tovmassian/escuadra/milestone/5). **Branch:** `feat/114-results`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Results to spec §3. The screen has:

- a top bar: close, the context, and a share button;
- the score in Archivo, with the escuadra corner;
- a tier title and a verdict line;
- a round strip of ten numbered segments;
- the missed players as swipeable player cards, or the ten players in circles on a 10/10;
- fewer actions: one main button, "Study this squad", and retry as an icon;
- "Photo credits · N".

The motion is spec §6's Results rows, at `MOTION_TIME_SCALE` 1. The haptics fire for a pass and a 10/10. "Study these N" is gone.

**Architecture:**

- Copy and actions are pure, tested helpers in `lib/resultsView.ts`.
- The new shared `PlayerCard` (spec §5.2) and `RoundStrip` are presentational; Study will reuse `PlayerCard` in #115.
- The screen is rewritten.
- The share button keeps today's text share (`formatShareText`, `Share.share`, `result.shared` unchanged). Part 2 swaps it for the sheet.
- No new package, no telemetry change, no privacy change.

**Tech Stack:** React Native 0.86, Expo SDK 57 (expo-image, expo-linear-gradient), Reanimated 4.5, TypeScript strict, Vitest.

**Spec:** [`docs/superpowers/specs/2026-10-15-play-redesign-2-0-design.md`](../specs/2026-10-15-play-redesign-2-0-design.md) §3 (Results), §5.2 (player card), §6 (Results motion), §7 (haptics: round passed, a la escuadra), §12 (SCREENS.md invariant 10), §13.

## Global Constraints

- Node 24: run `nvm use` in every new shell.
- **Guardrail 5.**
  - All colour, size, spacing and duration come from `theme/tokens.ts`.
  - Colour is read through `useThemeColors()` at render.
  - A module-scope `StyleSheet.create` holds only colour-free layout.
- **Motion.**
  - Results keeps the celebration carve-out: its timeline may run past 300 ms (spec §6).
  - With Reduce Motion (`useReducedMotion()`), nothing shakes, bounces, slides or scales: colour and opacity only.
  - Use `riseIn` from `components/riseIn.ts` for rises. It handles Reduce Motion and web.
- **Haptics** only through `feedback()` from `@/lib/haptics`.
- **Invariant 10:** the actions differ by pass or fail, and by whether the level ceiling is reached.
- **Close always chooses a different team** (spec §3.2).
- **Guardrail 1:** the credit list stays. Never use a Commons file name or caption in visible text or a label.
- **Guardrail 2:** team identity is the marker's bands, never a crest. Flags are not used on this screen.
- **No new dependency, npm script, `app.json` change, telemetry event or property, or privacy text.**
- **New typography for a bold face sets no `fontWeight`** (#117).
- `lib/` helpers stay React-free and tested. Tests sit beside the code in `lib/` and `theme/`.
- TypeScript is strict with `noUncheckedIndexedAccess`; never weaken it, avoid `!`, never use `any`.
- **Before each commit:**
  - run `npx prettier --write` on the changed files;
  - run `npm run typecheck`, `npm run lint` and `npx vitest run`.
- Never write to /tmp; use the SDD workspace the controller names.
- Each commit ends with a `Co-Authored-By` line naming the model that wrote it.

## Decisions made in planning (flag them in the PR)

1. **The results timeline is a token, `resultsTimeline`.** It replaces `celebrationCascade` for Results:
   - the strip fills from 0;
   - the tier's beat is at 300 (fail) or 480 (passed, 10/10);
   - cards follow 60 ms apart and circles 40 ms apart;
   - the actions rise after the beat.

   `strikeTiming` keeps its role for the ball.

2. **The missed-card line.** It names the first wrong part:
   - a name: "You picked X";
   - a position: "Name right · position is MF, you said FW";
   - a club or nationality: "Name and position right · club is Barcelona, you said Arsenal".
3. **Corners and the strike.** A passed score's corner is the existing `EscuadraStrike`, sized so its crossbar is `sizes.corner.results.arm` long. A failed score's corner is two static grey bars.
4. **`MOTION_TIME_SCALE` goes to 1,** as the issue body and spec §15 confirm. `MOTION_DISTANCE_SCALE` stays.

```ts
export type PrimaryAction = 'nextLevel' | 'retry' | 'chooseTeam';

export interface ResultActions {
  primary: PrimaryAction;
  secondary: 'study';
  /** Retry as an icon beside Study, whenever retry isn't the main button. */
  retryIcon: boolean;
}

/**
 * Invariant 10 (spec §3.2):
 * - A failed round's main button retries it.
 * - A pass plays the next level, or, at level 3, chooses a different team.
 * - Study this squad is always the second action.
 * - The screen's close button always chooses a different team.
 */
export function resultActions(passed: boolean, hasNextLevel: boolean): ResultActions {
  const primary: PrimaryAction = passed ? (hasNextLevel ? 'nextLevel' : 'chooseTeam') : 'retry';
  return { primary, secondary: 'study', retryIcon: primary !== 'retry' };
}

export interface ResultCopy {
  title: string;
  verdict: string;
}

/** The tier's title and one line of verdict (spec §3.1). */
export function resultCopy({
  tier,
  level,
  teamName,
  season,
}: {
  tier: ResultTier;
  level: number;
  teamName: string;
  season: string;
}): ResultCopy {
  if (tier === 'excellent') {
    return {
      title: 'A la escuadra',
      verdict: `${teamName} · ${season}, level ${level}. Nothing missed.`,
    };
  }
  if (tier === 'passed') {
    return { title: `Level ${level} cleared`, verdict: 'You knew most of the starting XI.' };
  }
  const target = `${Math.ceil(PASS_RATIO * ROUND_LENGTH)}/${ROUND_LENGTH}`;
  return {
    title: 'These are the ones to learn',
    verdict:
      level >= 3
        ? `Score ${target} to clear level ${level}.`
        : `Score ${target} to unlock level ${level + 1}.`,
  };
}

const PART_NOUN = { position: 'position', club: 'club', nationality: 'nationality' } as const;

/**
 * A missed card's line, naming the first wrong part (spec §3.1):
 * - the name: "You picked …";
 * - a later part: what was right first, then the real value and the pick.
 * Empty when no part is wrong.
 */
export function missedLine(result: QuestionResult): string {
  for (let i = 0; i < result.parts.length; i++) {
    const answered = result.parts[i];
    const part = result.question.parts[i];
    if (!answered || !part || answered.correct) continue;
    const picked = part.options[answered.pickedIndex] ?? '—';
    if (part.kind === 'name') return `You picked ${picked}`;
    const right = part.options[part.correctIndex] ?? '—';
    const before = i === 1 ? 'Name right' : 'Name and position right';
    return `${before} · ${PART_NOUN[part.kind]} is ${right}, you said ${picked}`;
  }
  return '';
}

import { StyleSheet, Text, View } from 'react-native';
import { bannerBands, stageVeil } from '@/lib/stageView';
import { cardGradient, durations, radii, spacing, stage, typography } from '@/theme/tokens';
import { useThemeColors, useThemeName } from '@/theme/useTheme';
import type { PhotoCredit, TeamMarker } from '@/types/squad';

interface PlayerCardProps {
  /** Results: `sizes.playerCard.results.width`. Study: omitted, so the card
   *  fills its column. */
  width?: number;
  height: number;
  shirtNumber: number;
  name: string;
  /** One line beneath the name, e.g. "You picked Marc Pubill". */
  line?: string;
  photo: PhotoCredit | null;
  marker: TeamMarker;
}

// A player as a card (spec §5.2), on Results and Study: the photo (or the
// team's bands under the veil), the shirt number top left, a gradient, and
// the name with one line beneath. One component, so the two screens match.
export function PlayerCard({
  width,
  height,
  shirtNumber,
  name,
  line,
  photo,
  marker,
}: PlayerCardProps) {
  const colors = useThemeColors();
  const themeName = useThemeName();
  const bands = bannerBands(marker);
  const styles = StyleSheet.create({
    card: {
      width,
      height,
      borderRadius: radii.card,
      overflow: 'hidden',
      backgroundColor: colors.surface,
    },
    bands: { ...StyleSheet.absoluteFill, flexDirection: 'row' },
    veil: {
      ...StyleSheet.absoluteFill,
      backgroundColor: colors.veilInk,
      opacity: stageVeil(bands, themeName),
    },
    number: {
      ...typography.cardNumber,
      color: colors.onPhoto,
      position: 'absolute',
      left: spacing.sm,
      top: spacing.xs,
    },
    text: {
      position: 'absolute',
      left: spacing.sm,
      right: spacing.sm,
      bottom: spacing.sm,
      gap: spacing.xxs,
    },
    name: { ...typography.cardName, color: colors.onPhoto },
    line: { ...typography.cardLine, color: colors.cardLine },
  });

  return (
    <View
      style={styles.card}
      accessible
      accessibilityLabel={`${shirtNumber}, ${name}${line ? `. ${line}` : ''}`}
    >
      {photo ? (
        <Image
          key={photo.url}
          recyclingKey={photo.url}
          source={{ uri: photo.url }}
          style={StyleSheet.absoluteFill}
          contentFit="cover"
          contentPosition={stage.focal}
          transition={durations.reveal}
          cachePolicy="disk"
        />
      ) : (
        <>
          <View style={styles.bands}>
            {bands.map((band, i) => (
              <View key={i} style={{ flex: band.weight, backgroundColor: band.color }} />
            ))}
          </View>
          <View style={styles.veil} />
        </>
      )}
      <LinearGradient
        colors={cardGradient.colors}
        locations={cardGradient.locations}
        style={StyleSheet.absoluteFill}
        pointerEvents="none"
      />
      <Text style={styles.number}>{shirtNumber}</Text>
      <View style={styles.text}>
        <Text style={styles.name} numberOfLines={2}>
          {name}
        </Text>
        {line ? (
          <Text style={styles.line} numberOfLines={2}>
            {line}
          </Text>
        ) : null}
      </View>
    </View>
  );
}

    >
      {items.map((item, i) => (
        <Segment key={i} index={i} no={item.no} correct={item.correct} />
      ))}
    </View>
  );
}

function Segment({ index, no, correct }: { index: number; no: number; correct: boolean }) {
  const colors = useThemeColors();
  const reduced = useReducedMotion();
  const fill = useSharedValue(0);
  useEffect(() => {
    fill.value = reduced
      ? withTiming(1, { duration: durations.transition })
      : withDelay(
          index * resultsTimeline.segmentStagger,
          withTiming(1, { duration: resultsTimeline.segmentFill }),
        );
  }, [index, reduced, fill]);
  const filled = useAnimatedStyle(() => ({ opacity: fill.value }));
  return (
    <View style={styles.cell}>
      <View style={[styles.track, { backgroundColor: colors.border }]}>
        <Animated.View
          style={[styles.bar, { backgroundColor: correct ? colors.success : colors.error }, filled]}
        />
      </View>
      <Text style={[typography.stripNumber, { color: correct ? colors.textMuted : colors.error }]}>
        {no}
      </Text>
    </View>
  );
}

const styles = StyleSheet.create({
  row: { flexDirection: 'row', gap: spacing.xxs },
  cell: { flex: 1, minWidth: 0, alignItems: 'center', gap: spacing.xxs },
  track: {
    alignSelf: 'stretch',
    height: sizes.segment.results,
    borderRadius: radii.xs,
    overflow: 'hidden',
  },
  bar: { ...StyleSheet.absoluteFill },
});
```

The fill is an opacity rise, not a width sweep. That keeps it within Reduce Motion's rules, and it reads left to right through the stagger.
